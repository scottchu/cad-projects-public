# My 3D Printing Journey With AI Agents

An offline 20-slide HTML talk for a 20–30 minute lunch and learn, following downloaded prints, personal ideas, agent-assisted learning and actual XT60 and Laifen evidence. A sandboxed Laifen clearance study opens inside the same page, with reset and photographed/rendered fallback evidence.

Open index.html locally, or the existing private /lunch-and-learn endpoint. Navigation: arrows/Space, N notes, S sources, O overview, Escape close. See [PRESENTER_GUIDE.md](PRESENTER_GUIDE.md) for timing and the90-second demo.

From the repository root:

```sh
npm run build --workspace cad-agent-lunch-and-learn
npm run check --workspace cad-agent-lunch-and-learn
```

Source: build.mjs, deck.css and simulator.mjs. Exact audited inputs were copied to assets/journey with hashes and source/snapshot associations in provenance.json. index.html embeds its required media and runtime. No CAD or printer is operated by this page.
