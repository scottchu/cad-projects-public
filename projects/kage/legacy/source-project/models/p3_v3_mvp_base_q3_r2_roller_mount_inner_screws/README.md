# Q3 r2 roller mount + inner screws release

CAD brief:

- One accepted r0 120-degree sector is the canonical plate and is printed three times.
- Every seam retains exactly four base bores: diameter 3.3 mm at radii 76 and 118 mm, tangential offsets -7 and +7 mm.
- One canonical two-bore roller-mount base uses only the outer radius-118 pair and is rotated to 60, 180, and 300 degrees.
- The mount seats at the plate top plane. Its local footprint is the r0 witness footprint enlarged only at deficient bore edges to give at least 3.0 mm material, while the existing +17.2 mm tangent reach provides contact with the second lap owner.
- Assembled and service STEP views include simplified M3 screw/nut hardware envelopes for both the inner plain pair and outer mount pair. Hardware is not a printable export.
- Printable outputs are only the canonical sector x3 and canonical roller mount x3.

The `p3_v3_mvp_base_q3_r1_canonical_four_hole_seam_clamp` directory is preserved unchanged but rejected for this release because its standalone four-hole clamp contradicts the r2 contract. No r2 clamp part or clamp export exists.

CAD validation does not prove screw fit, print tolerances, joint strength, roller performance, or service usability. Those remain physical-test gates.
