# Q4-R3 integral-lap MVP artifacts

Exactly four printed quadrant solids: Q1/Q3 role A with integral underside tongues,
and Q2/Q4 role B with underside-open rebates. The assembled and exploded STEP
files include eight M3x6 screws and eight loose M3 nuts for interface review.
The model-only 3MF contains only the four printed quadrants.

CAD evidence does not prove printed fit, strength, screw pull-through, nut
retention, or assembled flatness. Print and assemble this base before adding the
motor, rings, light, or electronics.
