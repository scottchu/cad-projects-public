# Q4-R4 functional centered step-lap MVP base

This isolated source-generated revision is the first functional chassis gate:

- four printable quadrant solids only;
- OD300 / ID132, 6.00 mm plate growing rearward from Z=-25.50;
- complementary centered 3 + 3 mm step-laps;
- top-loaded replaceable M3 nuts with M3x6 seam screws;
- twelve frozen Revision-K motor slots, two solid fixed-tower landings, and the
  distinct 300 degree spine's two D3.2 mounting paths;
- no controller/electronics holes.

Service order: remove the 300 degree structural spine before separating any
base quadrant.  Its lap-overlapping 20 x 24 mm footprint is intentional shared
chassis polymer; the complete top bearing area is continuous except for the two
frozen D3.2 mounting paths.

The STEP files are primary CAD artifacts.  The 3MF is model-only and contains
exactly four mesh objects.  CAD checks do not prove printed strength, nut fit,
preload/slip resistance, printed flatness, or purchased-component fit.
