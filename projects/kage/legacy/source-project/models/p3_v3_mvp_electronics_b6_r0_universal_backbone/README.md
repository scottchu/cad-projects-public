# B6-R0 universal electronics backbone MVP

One removable PETG printed solid mounted on the eight existing R4 seam axes. The assembled and exploded STEP files contain non-print board, hardware, cable, antenna, and thermal witnesses. Electronics envelopes are replaceable and no board-specific hole pattern is claimed. The 3MF is model-only and contains exactly the single B6 backbone. B4 moving rings remain the last assembly step.
