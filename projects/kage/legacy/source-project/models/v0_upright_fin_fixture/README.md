# V0 upright-fin manual optics fixture

Exactly four printed parts:

1. `fake_quartz_mask_body`
2. `second_carrier_hand`
3. `minute_carrier_hand`
4. `hour_carrier_hand`

Assembly order is body → second → minute → hour. The hour split collet is the
sole axial retainer. This model is a manual optics proof and is not compatible
with a real quartz movement.

Primary CAD: assembled/exploded STEP plus one STEP per printed part. Secondary
print exports live under `print/`. See
`docs/v0-upright-fin-fixture-physical-test-plan.md` before printing.
