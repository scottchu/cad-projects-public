# V0R1 compact representative-quartz fixture

This is a four-part manual optics prototype built around a compact envelope that
represents a common AA quartz movement. It is not a certified fit for any
purchased movement.

Exactly four printable parts:

1. `fake_standard_quartz_body`
2. `second_carrier_hand`
3. `minute_carrier_hand`
4. `hour_carrier_hand`

Assembly order is body, second, minute, then hour. The hour split collet is the
sole axial retainer. The upright rim fins—not the horizontal carrier rings or
spokes—are the intended shadow blockers.

Primary CAD consists of assembled and exploded STEP files plus one STEP per
printed part. Secondary STL and named four-object 3MF exports live under
`print/`. The manifest remains `pending_independent_review`; implementation
does not self-approve the design.

Follow `docs/v0r1-compact-quartz-fixture-physical-test-plan.md` before printing
or attaching any real LED or clock movement.
