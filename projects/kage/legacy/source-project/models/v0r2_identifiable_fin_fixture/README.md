# V0R2 identifiable-fin manual optics fixture

This isolated revision preserves the accepted V0R1 compact quartz envelope,
carrier stack, radii, source position, and four-part print architecture.  It
changes only the upright shadow-blocker identity:

- hour: 4.8 mm stem, 3.2 mm flat crown;
- minute: 3.2 mm stem, 1.6 mm flat crown;
- second: 1.6 mm stem, 0.4 mm flat crown.

Each crown tapers inward at 45 degrees and prints upright without support.
Exact overlap still obeys normal optical occlusion: the longest hand remains
visible beyond shorter endpoints, while the shared segment is owned by the
widest silhouette.
