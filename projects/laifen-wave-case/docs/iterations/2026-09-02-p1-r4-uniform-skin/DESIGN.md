## One field over the entire sidewall

Let N=round(2*pi*Rvalley/arc_pitch_target), P=2*pi*Rvalley/N. At defaults N34, P approximately3.61283. Let wrap(t)=t-floor(t+0.5), u=N*(theta-phase_theta)/(2*pi), v=(z-phase_z)/4.8, m=max(abs(wrap(u+v)),abs(wrap(u-v))). Define F=clamp((0.5-m)/(0.5-0.18),0,1).

On BOTH parts `r(theta,z)=Rvalley+skin_height*F(theta,z)-b(z)`. No separate collar field, smooth external strip or2mm fade. Body domain[-35.1,0]; cap[0,43.4]. b=0 except at the closed bed edge: if distance t from that edge is in[0,0.30], b=0.20*(1-t/0.30). The0.30mm relief remains textured with unchanged F amplitude and is the sole departure from the constant crest cylinder. At each relief's inside edge radius is continuous; shared topological edges are required. Do not apply this relief at z0.

Preserve axial4.8, target circumferential3.63 and blunt fraction0.18. Integer count changes31->34 because the new diameter increases; keeping31 would enlarge arc pitch. Common count34 and identical phase on body/cap keep seam continuity. A length increment changes domain bounds and cell count, never scales z or adjusts pitch; only a focused +4.8 length scalar check is required now, no nondefault CAD release.

Developed minimum plateau width `2*a*P*pz/hypot(P,pz)` is about1.039mm. Full-amplitude radial-z slope bound `h/(pz*(0.5-a))=0.29296875`; textured bed relief adds0.20/0.30 =>0.95963542, below1 (45deg from vertical bound) in either specified print orientation.
