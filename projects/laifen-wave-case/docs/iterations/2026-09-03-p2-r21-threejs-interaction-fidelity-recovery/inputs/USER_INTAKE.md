# P2 R21 user intake

The user requires the real Three.js preview to finish as an inspectable product simulator. R20 is retained as a noncandidate baseline: it established real WebGL, equal-diameter two-piece form, exploded presentation, Basic/Advanced tiers, and an honest conceptual-only disclosure, but independent validation and critique rejected its raw-state scene dependency, string-length label geometry, missing explicit pattern builders, failed orbit interaction, incomplete six-context browser proof, visually collapsed families, and clipping.

R21 is limited to those blockers. It must build only from the frozen R10 descriptor, make labels and patches from descriptor dimensions, implement ten named pattern builders, provide working orbit inspection and useful fixed views, fit every visible object, and make closures, patterns, fades, relief modes, drains, polygon progression, end profiles, and attachment families legible in current browser screenshots.

R21 may change only its new preview, tests, scratch evidence, and iteration receipts. R20, R10 core, the P2 R3 live route, P1 R7 CAD, OpenSCAD, exports, slicer state, and physical claims remain read-only. Nothing becomes live until independent validation, visual critique, and formal review pass the same frozen R21 candidate.
