# P2 R6 exact label-system contract

Frozen predecessor: R5 fingerprint `793e85802069802c9592a32702f22a2af235323c407d365ba3df40c6c14cdd06`; R5 is superseded with no implementation candidate. Start clean after inventory.

`textString` has 1…48 Unicode code points from a documented safe printable allowlist; render only as `textContent`/canvas glyphs, never `innerHTML`. Generic preview families map to fixed CSS stacks. `openScadFontFamily` is a future explicit string boundary only: browser selection cannot prove OpenSCAD availability, glyph coverage, metrics or fallback.

Let target global z be `z=lower?axial: H-axial` for lower and `z=upper?H-axial:axial` for upper, with `both` applying independently. Text tangent frame is `{normal=sectionSupport(theta), tangent, globalZ}`; horizontal advances tangent, vertical advances global Z. The upper uses its locked shape/pattern transform, so assembled round/polygon alignment remains. Text bounding rectangle is conservatively `width=0.72*textSize*glyphCount`, `height=textSize`, expanded by margin. Its global angular span is `width/support(theta)` and z span is height.

For every target reject if expanded label overlaps: seam zone `abs(z-(H-S))<K+height/2`, closed-end zones, active closure/thread band, global pattern keepout, accessory envelope/attach zone, or an enabled sibling label. Patch mode requires finite margin >=0 and applies a smooth rectangular fade to all texture fields under the expanded rectangle; patch itself remains within core support. `inset` returns negative relief, `outset` positive relief; text envelope is `core OD + 2*max(0,textRelief)` and combines with accessory envelope in the readout. Enforce textSize>0, `abs(textRelief)<=min(wall, floor)-0.2`, finite angle/axial values and target-local bounds. Any error clears geometry/detail/scale, sets field `aria-invalid`/error associations, and updates the live status.

Required tests: hostile HTML strings never create nodes; long/invalid glyph text clears preview; round and triangle/hexagon/octal rotated support placements have finite frames; each mode/target/orientation affects correct piece(s); labels collide at seam/end/closure/keepout/accessory and are rejected; patch makes texture weight zero inside and restores outside; text/accessory envelope readout is monotonic; mobile and assistive labels remain usable. Pattern/shape phase matching and no-collar core invariants retain all R5 tests.

Extend `accessoryMode` with `keyring_tab` and `bridge_handle`; `accessoryPrintMode∈{fixed,separate_visual}`. Validate positive finite member thickness, hole diameter, bridge span, standoff, mount angle and attach half; reject hole diameter plus two members exceeding tab width, bridge/label/seam/end/closure/patch intersections, and attach-interface overlap outside its explicit allowance. `totalEnvelope=max(coreOD,textEnvelope,accessoryEnvelope)` is always visible. A metal keyring/chain is an optional labelled reference silhouette only, excluded from generated printable geometry and all core dimensions. Test each mode, invalid/collision clear, total-envelope monotonicity and core-OD invariance.
