## Selected construction and boundaries

Replace the diamond-only twisted V-groove subtraction with one closed, triangulated, field-derived outer blank per component. Evaluate the preserved R7 rational field in SCAD, directly construct its exterior, then apply the existing interior/thread/drain Boolean operations. This avoids thousands of crossings between two long twisted cutter meshes. It is a performance hypothesis to test with the pinned real browser Manifold runtime, not a timing claim.

Keep the existing smooth outer-blank and shoulder branches as the regression oracle. Smooth must not traverse the new tessellation path. Do not replace build123d R7 or regenerate its artifacts. The user explicitly selected OpenSCAD WASM as this editable preview's geometry authority; this bounded work produces source-driven browser/STL evidence and does not claim new primary STEP acceptance.

Units are mm; XY is the circular section and +Z is the case axis. Body local/global Z=0 is its outer closed end. Body mating shoulder remains `S=body_thread_z=cap_close_z`; cap local Z=0 maps to global Z=S. The use sequence remains select parameters/output, Generate, inspect the actual compiler result, download that result, or select another component and regenerate. No printing action is part of this work.

The following are invariants: default OD39, bores30/31, floor3, end chamfer1.2 and its existing range; all split/length/overlap equations; male/female thread profile, pitch, depth, clearance, engagement, transition, root overlap epsilon, relief and placement; seven-hole drainage construction and its selector; two original component roles and all existing output transforms. Do not import R7's different thread or print-layout transforms under the name of exterior fidelity. Default dimensions remain cavity213, closed length219, body height144, cap height84, seam Z135, engagement6, overlap9. The body exterior ends at Z135 while its neck reaches Z144.

Existing `print_layout()` leaves the cap in its existing local pose; the older R7 openings-up requirement is not thereby proven. Preserve that transform in this correction, record the inherited orientation gap, and make no print-ready claim.

## Pure-math contract

Implement named pure SCAD functions before polyhedron/Boolean construction. Python may provide an independent analytic oracle, and schema may mirror preflight equations; neither may generate or substitute the displayed surface. Test executable SCAD function witnesses through an isolated echo/probe harness, so agreement between two copied host-language formulas alone cannot pass the gate. Production body and cap callers must both delegate to the same functions.

Suggested function responsibilities (names may change only with a documented direct mapping):

| Function | Inputs and behavior |
|---|---|
| `diamond_count` | `Rvalley, target_arc`; `floor(2*PI*Rvalley/target_arc + 0.5)`, reject outside 8..128; never clamp a bad count into validity. |
| `diamond_wrap` | `t - floor(t + 0.5)`, representing [-0.5,0.5); positive/negative periods must agree. |
| `diamond_coordinates` | `theta_deg, z_global, phase_deg, seam_z, N, axial_pitch`; `u=N*(theta_deg-phase_deg)/360`, `v=(z_global-seam_z)/axial_pitch`. |
| `diamond_field` | `u,v,a`; `m=max(abs(wrap(u+v)),abs(wrap(u-v)))`; `f=min(1,max(0,(0.5-m)/(0.5-a)))`. |
| `diamond_radius` | `Rvalley + depth*f`; sole exterior field evaluator used by both roles and all tessellation witnesses. |
| `diamond_global_z` | Body local Z is global Z; cap local Z maps to `S+z_local`. No independent component phase or Z scaling. |
| `diamond_patch_coordinates` | `s=i+x, t=j+y`; `(u,v)=((s+t)/2,(s-t)/2)` and its inverse `(s,t)=(u+v,u-v)`. Converts one reusable facet construction to the common cylindrical frame. |
| `diamond_constraints` | Finite/domain checks, widths/slopes/ligaments below, and a conservative preallocation complexity estimate. No BREP, file I/O, or tessellation in this function. |

Use `Rcrest=outer_diameter/2`, `Rvalley=Rcrest-diamond_depth`, `a=diamond_plateau_half_fraction`. Add the meaningful source parameter `diamond_plateau_half_fraction=0.18`; it is dimensionless, not 0.18 mm and not a V-groove-width multiplier. The naming prefix keeps it in the existing Surface group. Public proposed range is 0.10..0.30, with the derived constraints below; reject invalid combinations instead of silently adjusting them. Retain axial pitch4.8, target arc3.63, depth0.45 and angular phase0 as defaults. Treat `diamond_phase_deg` as the common angular phase at the seam datum, matching R7's seam-centered Z origin. A full phase turn and a repeat rotation must reproduce geometry.

At defaults:

- N=33, actual valley arc `A=2*PI*19.05/33=3.627111518 mm`.
- Plateau developed width `W=2*a*A*P/sqrt(A*A+P*P)=1.041776914 mm` for P=4.8.
- Field radius is bounded by 19.05..19.50, reaches both endpoints, and equals the crest for `m<=a`.
- Axial slope bound is `depth/(P*(0.5-a))=0.29296875`; no axial scaling as lengths or split change.
- The field continues through the seam: evaluate both roles at the same global S, not at unrelated local zeros. Their exterior limiting radii must agree at every theta.

For positive-depth diamond jobs require finite values, positive radii/pitches, `0<a<0.5`, N in8..128, W>=1.0 mm and axial slope<=1. Retain current source/schema numeric ranges unless the above joint constraints reject a combination. Width and slope bounds preserve R7's selected motif constraints; they do not prove grip or print quality. At depth=0 bypass the diamond tessellation and use the exact smooth geometry; count can remain a readout, but irrelevant plateau-width/slope constraints must not prevent the smooth-equivalent result.

For a textured cylindrical band, require valley-to-body/cap-bore wall >= `minimum_wall` and valley-to-female-thread-crest-plus-clearance >=1.8. Default values are 4.05, 3.55 and 1.90 mm respectively. Keep the existing male root >=1.2 rule and all other internal preflights. Check the female entry relief separately against the same valley radius and its actual local void. At defaults its outer radius16.65 leaves2.40 mm. A depth0.60/default-thread job leaves only1.75 mm at the female groove and must now fail before compilation. Preserve the old smooth constraints when style is smooth: a dormant depth value must not alter smooth eligibility. Reject NaN, infinity, missing/blank numeric input and excessive mesh allocation before worker start.

## Exterior tessellation and shoulder contract

Use the R7 facet partition in developed `(s,t)` space. For each integer cell `(i,j)`, the outer square has corners `(+-0.5,+-0.5)` and valley radius; the inner square has corners `(+-a,+-a)` and crest radius. One inner plateau plus four connecting ramp polygons covers the cell. Convert all polygon vertices with the shared `(s,t)->(u,v)` function. Tile only cells intersecting one circumferential period and the requested axial interval. This preserves plateau and valley breaklines directly, unlike a coarse uniformly sampled field that may miss them.

Clip the developed patches to one common angular interval spanning exactly N periods and to each component's true exterior endpoints. Clip using deterministic shared-edge intersections; subdivide neighboring faces consistently, index common vertices once, and wrap the angular boundary to the same indices. No duplicated unjoined circumferential seam, T-junction, zero-area face, open rim, or self-crossing face is permitted. Triangulate all nonplanar polygons explicitly. Split long edges consistently enough that radial interpolation error from cylindrical chords is <=0.025 mm, verified independently; do not increase tessellation everywhere without identifying the failed error bound. Boundary rings and end-cap fans must use the exact same perimeter indices as their adjacent walls. The outer blank is one closed positive-volume polyhedron, not one Boolean solid per diamond.

The tessellated blank initially spans body `[0,S]` or cap-local `[0,cap_height]`. Apply the existing 45-degree circular chamfer envelope to the diamond blank at the body bottom/cap top, with unchanged end radius and plane. This is an intersection with the existing source-derived outer envelope, not a new smooth collar. Preserve a circular closed-end rim and the existing floor. The texture may end only where the inherited chamfer envelope trims it; do not restore the previous 2 mm end margins.

In the diamond body branch, the existing `translate([0,0,S-1]) cylinder(r=outer_radius,h=1)` must not refill the field and create a 1 mm smooth ring. The new outer blank already reaches the shoulder plane; omit that redundant full-radius union only for diamond, or intersect it with the same field before union. Preserve the positive external seating plane at S, neck/threads, and the remaining annular material. Check actual contact area and absence of interpenetration using the generated pair. Smooth keeps the original union unchanged.

Cap texture starts at local Z0, including outside the entire female-thread region; body texture ends at global S. No exterior 2 mm/11 mm collar remains. The radial ligand checks above are mandatory because this expands texture into the cap's thread zone. Do not cut into internals to rescue a failing valley wall.

## Performance budget, retries and stop conditions

Preallocate only tiles intersecting the requested finite domain; reuse field values/vertex indexing, triangulate once, and use a single exterior polyhedron per part. Avoid Boolean unions per tile, crossing helical cutter subtraction, recursive whole-surface refinement, added JS mesh synthesis and indiscriminate `$fn` increases. Keep the existing thread tessellation and smooth `$fn=96` unchanged. Start with a conservative cap of250000 exterior triangles per component, reject jobs exceeding the analytic estimate before allocation, and record the estimator versus actual counts. This is a memory guard, not evidence that250000 triangles are fast enough. Do not add a visible quality knob in this correction.

Initial benchmark ceiling: short-band G2 must complete within30 seconds; default body/cap within60 seconds each; default assembled/print-layout within120 seconds each, measured cold end-to-end browser worker completion including probe and result delivery. The existing180-second UI watchdog remains a final failure guard. These are acceptance targets selected to improve on the existing60-second no-output failures, not observed speeds. Record cold wall time separately from engine and geometry time. Require one cold and one subsequent successful default assembled run; do not run broad parameter grids. A validated complexity cap plus a deliberately chosen higher-cost feasible case bounds the enabled control domain; reduce that domain explicitly if it cannot meet the ceiling.

Implementation has one initial attempt plus at most two focused repair cycles on the frozen design. Checkpoint after cheap math and after the first actual exterior/part failure, with qualitative one-workstream, modest-output ceilings when runtime token/time controls are unavailable. A timeout consumes an attempt; do not repeatedly run the same failing long job. Keep one writer and at most three dependency-ready workers overall. Implementation, critic, validator and formal reviewer must have distinct identities; critic and validator may work in parallel only after a candidate manifest is frozen, followed by the formal-review join.

Stop and return the smallest failed invariant on: input drift, absent exact-source witnesses, math/intent failure, mesh self-intersection/open topology/multiple part fragments, lost plateau or seam collar, unacceptable valley wall, changed protected internals/transforms, actual interpenetration, timing/triangle ceiling, unverified browser output identity, or need for broader worker protocol changes. After two repairs, reopen design or reduce the supported diamond domain. Never rescue a failing candidate by hiding diagnostics, enabling controls anyway, extending timeouts, shrinking depth/pitch silently, or changing thread/bores.

Physical grip comfort, actual fit/closure force, remaining-wall strength, wear, support-free slicing, drainage and exact printed-reference identity remain unvalidated. Intended U1 PLA/0.4 mm nozzle/0.2 mm layers and openings-up print orientation remain profile intentions, not acceptance. P1 R7 source/STEP authority is preserved.
