# Recovery design

Use plain HTML/CSS and classic local scripts so opening `index.html` works
without a server, package installation or network. Preserve CAM LAB's existing
warm canvas, dark controls and yellow action color. This is a precisely scoped
reconstruction within the existing visual system, not a new product identity.

The primary YZ editor shows complete fixed-inner tracks and distinct OPEN/END
handles; each outer plate has a separate static local drawing. A shared motion
slider moves rod markers through the computed paths, never recomputes the cuts
from the current animation state. Numeric endpoint inputs provide an alternative
to dragging. User edits are explicitly experiments, not accepted CAD updates.

Pure `geometry.js` is shared by UI, diagnostic calculations and SVG export.
The recovered P20 R4 profile supplies exact trigonometric OPEN and base-END
coordinates plus shared offset. Straight interpolation is the supported recovered
path contract; unrecorded original arch/bias controls are not invented.

Local storage is a convenience, JSON download is portable persistence. Loading
is transactional and rejects unsupported schemas, missing rods, nonfinite and
out-of-range values. Reset restores the recovered default. Diagnostics use sampled
centerlines, not actual solids or proof of whole-product clearance. Full mechanism,
wire/XT60 collision, cap/axle fit and physical behavior remain outside this tool.
