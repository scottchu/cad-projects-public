# P25 R1 後環＋前壓桿快速夾具 brief

日期：`2026-09-05`  
設計角色：`P25-DESIGN-02`  
狀態：**設計契約完成；僅供第一版 CAD 預覽；不可用於列印或物理驗收**

## 使用者已確認的操作

1. 大拇指把 Orange 往下推。
2. 食指與中指把 Blue、Green 從後往前推。
3. 三支金屬桿都由手指移動；夾具不得驅動、同步或改變任何既有滑軌路徑。
4. 三支桿到達既有 `CLAMPED_END` 後，夾具才取代手指維持狀態。
5. 解開快扣後，前壓桿必須立即離開 Orange，不可依賴翻轉機構或重力才釋放。

## 選定架構

在金屬桿左右兩端各使用一個 X 軸鏡像的可拆式側邊模組：

- 後方一體式 `rear_yoke` 同時承托 Blue 與 Green；
- 前方鉸接 `front_pusher_bar` 只接觸 Orange；
- 一側為 X 軸方向鉸鏈，另一側為單手快扣／鉤；
- 鉸鏈設開啟偏壓空間，使快扣解除後前壓桿立即旋開；
- 左右兩端同時夾持，以降低單邊受力使桿傾斜的風險。

夾具形成獨立閉合受力圈：
`Orange -> front pusher -> front bar -> hinge/latch -> rear yoke -> Blue+Green`。
夾具不固定在內外板上，也不以 XT60 本體作反力點。

## 不可變條件

- 三支現有金屬桿保持精確 `OD4.00 x 50.00 mm`，不可改長度。
- 金屬桿端點保持 `X=+/-25.00 mm`。
- 不使用舊 cap，cap 數量為零。
- 不使用 P24 screw cassette、螺桿、壓板或浮動 shoe 架構。
- 不修改既有內外板、固定桿、滑軌、桿身份、桿路徑或 XT60 位置。
- P24 保留為 rejected history；P25 不覆寫其 source、artifact 或紀錄。
