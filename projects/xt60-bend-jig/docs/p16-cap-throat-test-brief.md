# P16 PETG cap-throat test

- Finding addressed: all three P15 caps were far too tight because their common 3.60 mm entry throat dominated the cavity size.
- Model: three separate upright slit-cap specimens; no mechanism modification.
- Constant geometry: 4.20 mm cavity, 0.60 mm radial slit, 7.00 mm OD, 3.80 mm height, 0.80 mm closed floor.
- Independent variable: entry throat diameter 4.05, 4.10, or 4.15 mm, left to right.
- Identification: identical 7 x 5 x 1.2 mm handling tags engraved `405`, `410`, and `415`.
- 0.4 mm nozzle contract: explicit seven-segment digits use 0.80 mm strokes and 0.40 mm engraving depth.
- Print orientation: closed cap ends and handling tags on the XY bed; rod entries face +Z.
- Primary artifact: `cad/p16_cap_throat_test/p16_cap_throat_test.step`.
- Secondary artifact: `cad/p16_cap_throat_test/p16_cap_throat_test.3mf`.
- Physical test order: start at 4.15, then 4.10, then 4.05; record insertion, removal, shake retention, and ten-cycle fit.
