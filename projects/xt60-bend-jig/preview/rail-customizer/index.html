How the rails are calculated

The inner path interpolates OPEN and END, plus a smooth quadratic bend: P(u) = (1−u) OPEN + u END + 4u(1−u) curve offset. The curve dot is the actual midpoint P(0.5). Zero offset restores a straight path. A rotating outer plate needs the local slot R(−θu)P(u); rotating that point forward returns the same rod position.

Drag a line to translate both endpoints together. Drag either endpoint to move it independently, or the curve dot to bend the path. Controls that coincide are spread apart with short leader lines so each stays draggable.

The purple axle stays fixed in the world. Its outer guide is the inverse rotation of the profile’s fixed axle position, (−10, −10) by default. The inner purple circle is an axle reference, not its hex-bore cut.
